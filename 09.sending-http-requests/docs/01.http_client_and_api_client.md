# HTTP Client & ApiClient Wrapper

Calling low-level `http` functions directly inside your repositories or UI leads to duplicate code for headers, base URLs, timeouts, and error handling.

To keep things clean, we build a centralized `ApiClient` wrapper and inject it using Riverpod.

## Adding the `http` Dependency

Add the `http` package under `dependencies` in `pubspec.yaml`:

```yaml
dependencies:
  flutter:
    sdk: flutter

  # Network
  http: ^x.y.z
```

## Designing the `ApiClient`

Build `ApiClient` to handle all network communication. It wraps `http.Client` and resolves relative paths against a `baseUrl`.

### Key Responsibilities:

1. **Resolve endpoints**: Concatenate relative paths with the `baseUrl`.
2. **Set standard headers**: Include `'Accept': 'application/json'` and `'Content-Type': 'application/json'` in requests.
3. **Enforce request timeouts**: Limit requests to a maximum duration (e.g., 30 seconds) using `.timeout()`.
4. **Encode and decode payloads**: Serialize request maps to JSON strings and parse JSON responses.
5. **Extract payload data**: Retrieve the nested `'data'` field automatically if the API returns a `{ "data": ... }` wrapper.

### Implementation

```dart
import 'dart:async' show TimeoutException;
import 'dart:convert' show jsonDecode, jsonEncode;
import 'dart:io' show SocketException;

import 'package:http/http.dart' as http;
import 'package:my_store/core/network/api_exception.dart';

const Duration _timeout = Duration(seconds: 30);

class ApiClient {
  const ApiClient({required this.client, required this.baseUrl});

  final http.Client client;
  final String baseUrl;

  Future<dynamic> get(String path) {
    return _handleRequest(() {
      final call = client.get(
        Uri.parse('$baseUrl$path'),
        headers: {'Accept': 'application/json'},
      );
      return call.timeout(_timeout);
    });
  }

  Future<dynamic> post(String path, {Map<String, dynamic>? body}) {
    return _handleRequest(() {
      final call = client.post(
        Uri.parse('$baseUrl$path'),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
        body: jsonEncode(body),
      );

      return call.timeout(_timeout);
    });
  }

  Future<dynamic> patch(String path, {Map<String, dynamic>? body}) {
    return _handleRequest(() {
      final call = client.patch(
        Uri.parse('$baseUrl$path'),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
        body: jsonEncode(body),
      );

      return call.timeout(_timeout);
    });
  }

  Future<dynamic> put(String path, {Map<String, dynamic>? body}) {
    return _handleRequest(() {
      final call = client.put(
        Uri.parse('$baseUrl$path'),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
        body: jsonEncode(body),
      );

      return call.timeout(_timeout);
    });
  }

  Future<dynamic> delete(String path) async {
    return _handleRequest(() {
      final call = client.delete(
        Uri.parse('$baseUrl$path'),
        headers: {
          'Content-Type': 'application/json',
          'Accept': 'application/json',
        },
      );

      return call.timeout(_timeout);
    });
  }

  dynamic _decodeBody(String body) {
    if (body.isEmpty) return null;

    try {
      return jsonDecode(body);
    } on FormatException {
      throw const ParsingException();
    }
  }

  Future<dynamic> _handleRequest(
    Future<http.Response> Function() sendRequest,
  ) async {
    try {
      final response = await sendRequest();

      final decodedBody = _decodeBody(response.body);
      if (response.statusCode >= 200 && response.statusCode < 300) {
        if (decodedBody is Map<String, dynamic> &&
            decodedBody.containsKey('data')) {
          return decodedBody['data'];
        }
        return decodedBody;
      }

      throw _mapErrorResponse(response.statusCode, decodedBody);
    } on SocketException {
      throw const NoInternetException();
    } on TimeoutException {
      throw const RequestTimeoutException();
    } catch (e, st) {
      if (e is ApiException) rethrow;
      throw Error.throwWithStackTrace(
        ServerException(statusCode: -1, message: 'Unknown error', error: e),
        st,
      );
    }
  }
}
```

### Design Decisions in `ApiClient`

- **Centralize the request lifecycle**: Pass network calls as callbacks to `_handleRequest`. This handles JSON decoding, status code checks, and network try-catch blocks in one place instead of duplicating them across every HTTP verb method.
- **Enforce timeouts on slow connections**: Dart's network client waits indefinitely if a server hangs. Chain `.timeout()` to throw a `TimeoutException` so the UI can recover and notify the user rather than hanging forever.
- **Safeguard JSON parsing**: Catch `FormatException` during body decoding and raise a custom `ParsingException`. This prevents the application from crashing when the API returns malformed payloads or unexpected HTML error pages.
- **Unwrap nested JSON responses**: Most APIs wrap successful results in a `data` field (e.g., `{ "data": [...], "meta": {...} }`). Extracting `body['data']` and returning it directly simplifies the response for repositories and mapping logic.

## Injecting Network Dependencies with Riverpod

Register `ApiClient` and `http.Client` as Riverpod providers in `network_providers.dart` to make them easy to mock, configure, and access from anywhere:

```dart
import 'package:http/http.dart' as http;
import 'package:my_store/core/network/api_client.dart';
import 'package:riverpod_annotation/riverpod_annotation.dart';

part 'network_providers.g.dart';

@Riverpod(keepAlive: true)
http.Client httpClient(Ref ref) {
  return http.Client();
}

@Riverpod(keepAlive: true)
ApiClient apiClient(Ref ref) {
  return ApiClient(
    client: ref.watch(httpClientProvider),
    baseUrl: 'https://your-app.domain/api/v1',
  );
}
```

> **Why `keepAlive: true`?** `http.Client` maintains an internal socket connection pool. Keep these providers alive for the entire application lifecycle to reuse connections instead of recreating them on every request.
