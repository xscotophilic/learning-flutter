# The `my_store` Showcase App

Transition the `my_store` app from local mock repositories to full REST API backend integration over HTTP. This update builds on top of the [Working with User Input & Forms Chapter](../../08.working-with-user-input-forms/docs/04.my_store_walkthrough.md).

The API is available at [https://victorious-determination-production-344e.up.railway.app/api/v1](https://victorious-determination-production-344e.up.railway.app/api/v1).

## What Was Added & Changed

### Network Layer Core

Introduce the core networking files under `lib/core/`:

```text
lib/core/
├── dependency_injection/
│   ├── network_providers.dart       # Riverpod providers for http.Client & ApiClient
│   └── network_providers.g.dart
└── network/
    ├── api_client.dart              # Centralized HTTP request wrapper
    └── api_exception.dart           # Domain exception taxonomy
```

1. **Configure `ApiClient`**: Route HTTP methods, configure request timeouts (30s), decode response JSON, and unpack top-level `'data'` envelopes.
2. **Define `ApiException`**: Classify connection failures and HTTP status code errors into a sealed exception taxonomy.
3. **Expose network providers**: Register Riverpod providers with `keepAlive: true` to manage persistent connection lifetimes.

### Concrete API Repositories

Replace mock repositories with concrete REST API implementations in the feature data layers:

- `ApiProductRepository` (`api_product_repository.dart`)
- `ApiCartRepository` (`api_cart_repository.dart`)
- `ApiFavoritesRepository` (`api_favorites_repository.dart`)
- `ApiOrdersRepository` (`api_orders_repository.dart`)

### Dependency Injection Wiring

Inject `apiClientProvider` into every repository provider inside `repository_providers.dart`:

```dart
@Riverpod(keepAlive: true)
ProductRepository productRepository(Ref ref) {
  return ApiProductRepository(ref.watch(apiClientProvider));
}

@Riverpod(keepAlive: true)
CartRepository cartRepository(Ref ref) {
  return ApiCartRepository(ref.watch(apiClientProvider));
}

@Riverpod(keepAlive: true)
FavoritesRepository favoritesRepository(Ref ref) {
  return ApiFavoritesRepository(ref.watch(apiClientProvider));
}

@Riverpod(keepAlive: true)
OrdersRepository ordersRepository(Ref ref) {
  return ApiOrdersRepository(ref.watch(apiClientProvider));
}
```

### Package Dependencies

Add the `http` package dependency to `pubspec.yaml`:

```yaml
dependencies:
  http: ^1.6.0
```

## Local Setup

Run these commands to set up and start the application locally:

```bash
cd my_store
flutter pub get
dart run build_runner build --delete-conflicting-outputs  # regenerate .g.dart files
flutter run
```
